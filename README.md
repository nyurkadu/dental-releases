# Dental X-ray Viewer — выпуски

Здесь только установщики программы Dental X-ray Viewer и описания версий: из этого репозитория установленная
программа узнаёт о новых версиях и обновляется (окно «О программе»). Исходного кода здесь нет.

**Установка:** откройте последнюю версию в разделе [Releases](https://github.com/nyurkadu/dental-releases/releases),
скачайте `DentalViewer-<версия>-setup.exe` и запустите его. Права администратора не нужны.
